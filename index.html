SIAKAD · Proyek UTS Manajemen dan Pemodelan Data

Web Aplikasi Sistem Informasi Perkuliahan

Aplikasi PHP 8 dan MySQL/MariaDB dengan tiga peran: administrator mengelola data dan jadwal, dosen menyetujui KRS dan menginput nilai, mahasiswa mengisi KRS serta melihat KHS dan transkrip.

▶ Jalankan aplikasi (GitHub Codespaces) Kode sumber di GitHub Laporan UTS (PDF)

Halaman ini adalah halaman statis. Aplikasinya sendiri memerlukan PHP dan MySQL, sehingga dijalankan di GitHub Codespaces: klik tombol kuning, login GitHub, tunggu sekitar 2 sampai 3 menit pada pembukaan pertama, lalu aplikasi terbuka otomatis di tab baru.

Fitur

Administrator

  • CRUD fakultas, prodi, dosen, mahasiswa, mata kuliah, ruangan
  • Kelas dan jadwal dengan deteksi bentrok
  • Manajemen akun dan dashboard statistik

Dosen

  • Persetujuan KRS mahasiswa bimbingan
  • Input nilai tugas, UTS, UAS dengan pratinjau nilai akhir
  • Jadwal mengajar

Mahasiswa

  • Pengisian KRS (kuota, bentrok, maksimal 24 SKS)
  • KHS per semester dengan IPS
  • Transkrip dengan IPK

Cara menjalankan

  1. Sekali klik dari GitHub: tombol Jalankan aplikasi di atas membuat server PHP dan MariaDB di GitHub Codespaces, mengimpor basis data otomatis, lalu membuka aplikasinya.
  2. MacBook: brew install php mariadb, brew services start mariadb, impor database/schema.sql dan database/seed.sql, lalu jalankan php -S localhost:8000 tools/router.php dan buka http://localhost:8000.
  3. Windows (XAMPP): salin folder ke htdocs/siakad, impor SQL lewat phpMyAdmin, buka http://localhost/siakad/.

Panduan lengkap ada di README.

Tangkapan layar

Basis data

Basis data db_siakad terdiri atas 12 tabel InnoDB dalam bentuk normal ketiga (3NF) dan 3 view untuk nilai akhir, IPS, dan IPK.
